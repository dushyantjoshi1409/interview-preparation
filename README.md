## Repository structure

```text
companies/
  <company-slug>/
    README.md
    JOB_DESCRIPTION.md
    INTERVIEW_PLAN.md
    resume.pdf
template/
  COMPANY_CHECKLIST.md
```

## Process for every company

1. Create `companies/<company-slug>/`.
2. Add the resume version submitted for that role.
3. Save a concise job-description summary and the original job link when available.
4. Research official company sources and clearly label candidate reports as anecdotal.
5. Create a role-specific interview plan with truthful resume evidence.
6. Add likely behavioral, technical, system-design, and coding questions.
7. Record unanswered details as placeholders instead of inventing experience.
8. Add post-interview notes while the conversation is fresh.

Use [the company checklist](template/COMPANY_CHECKLIST.md) to keep future preparation consistent.

## Privacy notice

This is a public repository. Review every resume and note before committing it. Do not add confidential employer information, credentials, private interview links, interviewer contact details, or sensitive personal data that should not be public.
